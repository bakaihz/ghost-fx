# Ghost FX

Toolkit Node.js para requisições HTTP, sessões de navegador e gerenciamento de projetos.

## Recursos

- Request Engine
- GET, POST, PUT, PATCH e DELETE
- Retry e timeout
- Cache TTL
- Controle de concorrência
- Rate limiting
- Métricas
- Browser Simulator
- Sessões persistentes
- Cookies e headers
- Redirects
- Histórico
- Project Manager
- CLI

## Instalação

```bash
npm install ghost-fx
```

## CLI

```bash
ghost request GET https://example.com
ghost browser open
ghost ls
ghost read package.json
```
